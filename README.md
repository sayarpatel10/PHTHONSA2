# ShopImpact - Conscious Shopping Dashboard

## Project Overview

ShopImpact is a Python-based web application that helps people understand the estimated environmental impact of their shopping choices.

Users can record purchases, view their monthly spending, calculate estimated CO2 impact and explore greener alternatives.

## Main Features

1. Product type, price and brand input.
2. Live estimated CO2 calculation.
3. Monthly spending dashboard.
4. Monthly estimated environmental impact dashboard.
5. Eco Saver and Low Impact Shopper badges.
6. Greener product and seller suggestions.
7. Turtle eco graphics.
8. Random environmental tips.
9. Motivational quotes.
10. Light, dark and high-contrast themes.
11. Purchase history.
12. CSV download.
13. Sample purchase testing.

## Technologies Used

- Python
- Streamlit
- Pandas
- Datetime
- Turtle Graphics

## How to Run the Project

1. Install Python.
2. Download the project files.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Install the libraries:

   pip install -r requirements.txt

6. Start the website:

   streamlit run app.py

## CO2 Calculation

The project uses the following calculation:

Estimated Impact = Product Price x Product Multiplier

The multipliers are example values for this educational project. They are not verified scientific emission factors.
